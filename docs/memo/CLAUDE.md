# docs/memo ディレクトリ 取扱ガイド

このディレクトリは **検討メモ・設計スケッチ・議事メモ** の置き場です。実装の一次情報ではありません。

## 重要な注意事項

- **このディレクトリの内容は古い可能性があります**
- ドキュメントに記載された仕様・スキーマ・API パス・環境変数名等は、実装時点から変更されている可能性があります
- **正確な最新状況は必ず以下で確認してください**:
  1. **コードベース** (`server/app/`, `frontend/src/`, マイグレーションファイル等)
  2. **ユーザに直接尋ねる**
- コードとメモに乖離がある場合は **コードを正** とする

## このディレクトリに置くもの

- 機能の設計検討メモ (`*_design.md`)
- 外部サービス設定手順のメモ (`*_setup.md`)
- 要件定義のドラフト (`*_requirements.md`)
- grill / ブレストの記録

## このディレクトリに置かないもの

- 実装ルール・コーディング規約 → `docs/coding_standards.md` や `.claude/rules/` へ
- プロジェクト全体の要件定義 (確定版) → `docs/requirements.md` へ
- コミット済みの API 仕様 → OpenAPI (自動生成) or `docs/` 配下の確定ドキュメントへ
- **実装後に恒久リファレンスとして参照される機能仕様** → `docs/<feature>.md` へ (例: `docs/notifications.md`)
  - memo には「決定過程・変遷・Phase 計画・Phase 2 候補」だけを残す
